Como está agora

    Ligar ao banco de dados

    Supabase → Project Settings → API

    Cole aqui os dois dados do seu projeto. A gente testa a conexão na hora e, se estiver tudo certo, monta o arquivo pronto para você copiar.

    Use a chave anon. Nunca cole aqui a service_role — ela dá acesso total ao banco e ficaria visível para qualquer visitante.

    Cotação das moedas

    O preço do site é em real. Se você preencher aqui, a loja também mostra o valor em dólar, guarani e peso — como referência, não como cobrança. Deixe vazio o que não quiser mostrar: moeda sem cotação simplesmente não aparece na loja.

    Arquivo pronto

    1. Copie o texto abaixo.
    2. Na Hostinger: Arquivos → Gerenciador de arquivos.
    3. Abra public_html/gestao/assets/ e clique com o botão direito em config.js → Editar.
    4. Apague tudo o que estiver lá, cole o texto copiado e salve.
    5. Volte nesta página e toque em Conferir de novo.
